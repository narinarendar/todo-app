# Todo App

A simple and interactive Todo application built using HTML, CSS, JavaScript, and Bootstrap.

## Features
- Add tasks
- Mark tasks as completed
- Delete tasks
- Save tasks and retain them after refreshing the page

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Bootstrap 4
- Font Awesome

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Project Purpose
Built to practice front-end web development and JavaScript DOM manipulation.
